# individual

指定されたキーに対してグローバルに一意なシングルトン値を作成するためのシンプルなユーティリティです。これは、プロジェクト内でモジュール自体が複数回読み込まれた場合でも、モジュールが持つキャッシュやリソースのインスタンスを確実に1つだけに保つために役立ちます。

## 問題: モジュールの重複インスタンス

複雑なJavaScriptプロジェクト、特にネストされた依存関係を持つ場合、同じモジュールが複数回読み込まれる可能性があります。これにより、いくつかの問題が発生する可能性があります。

-   **非効率なキャッシュ:** モジュールが内部キャッシュを保持している場合、インスタンスが重複すると、同期されていない別々のキャッシュが作成され、パフォーマンスが低下します。
-   **リソースの競合:** モジュールがWebSocket接続やネイティブC++拡張のインスタンスなど、一意のリソースを管理している場合、複数作成するとバグやアプリケーションのクラッシュを引き起こす可能性があります。

`individual`は、値を保存するための共有のグローバル名前空間を提供し、常に同じインスタンスが返されることを保証することで、この問題を解決します。

## 例

```js
import { Individual } from "https://code4fukui.github.io/individual/index.js";

// 最初の呼び出しでキャッシュが空のオブジェクトで初期化されます。
const moduleCache = Individual("__MY_MODULE_CACHE", {});

// 別のファイル、あるいはこのモジュールの複製でも、
// 同じキーでIndividualを呼び出すと*完全に同じ*オブジェクトが返されます。
const sameCache = Individual("__MY_MODULE_CACHE", { some: "other value" });

console.log(moduleCache === sameCache); // true
```

## API

### `Individual(key, defaultValue)`

-   **`key: string`**: グローバル名前空間（例: `window` や `global`）内で値を識別するための一意の文字列。
-   **`defaultValue: any`**: `key` がまだ存在しない場合に保存される初期値。同じキーによる以降の呼び出しでは、この引数は無視されます。
-   **戻り値**: 保存された値。最初の呼び出しでは `defaultValue` となり、以降のすべての呼び出しでは以前に保存された値となります。

## 仕組み

このライブラリは、グローバルオブジェクト（ブラウザでは `window`、Node.jsでは `global`）上の `key` を確認します。キーが存在する場合は、保存されている値を返します。存在しない場合は、そのキーに対して `defaultValue` を設定して返します。これにより、同じキーを使用するアプリケーションのどの部分でも、同じシングルトンインスタンスを受け取ることが保証されます。
